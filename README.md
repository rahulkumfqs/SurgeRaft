# SurgeRaft

SurgeRaft is a distributed, real-time processing framework for scalable systems with auto-scaling capabilities.

The key benefits of using SurgeRaft include:

- SurgeRaft is a distributed, real-time
- processing framework for scalable systems
- with auto-scaling capabilities

- python

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/SurgeRaft.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SurgeRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
